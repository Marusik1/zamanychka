## Comparison

- The shell uses the reference graphite/navy base with gold restricted to a thin rule, small marker, eyebrow, and status border.
- Mobile content remains centered, legible, safe within the narrow viewport, and uses nearly the full available width without horizontal overflow.
- Desktop uses a deliberately wider composition and restrained central frame rather than stretching mobile cards.
- Typography hierarchy and whitespace follow the calm premium tone of the two primary concept references.
- There are no game routes, arrows, board, pawns, decorative cards, glow-heavy effects, or product actions because those are outside EPIC-00.

Only the responsive foundation shell is assessed in this epic. Board prominence and gameplay composition become applicable in EPIC-06.

# Reference Map

This file is canonical input for the next visual EPIC. It defines what each source may influence and what it must not influence.

## Interland

Use for:

- Intro as an explorable scene instead of a dashboard.
- Loading and first reveal with a strong sense of place.
- Camera movement that teaches navigation.
- World-to-interface transitions.
- Interaction-led onboarding with minimal copy.
- Object feedback: hover, press, travel, settle.

Do not use for:

- Google palette.
- Islands, floating worlds, or geographic metaphors.
- Characters or child-oriented illustration.
- Educational theme.
- Bright primary-color visual language.

## SUGOROCKS

Use for:

- Board-game identity.
- Physical dice as an interaction object.
- Tactile scene changes.
- Navigation driven by game objects rather than generic decoration.
- Playful but brief motion.

Do not use for:

- Literal page composition.
- Any one-to-one copy of dice paths or page sections.
- Excessive novelty if it harms Telegram usability.

## Deep Green

Use for:

- Material restraint.
- Pawn/die quality targets.
- Board-first composition.
- Clean selection/hover states.
- Controlled lighting and quiet depth.

Do not use for:

- Chess-specific interaction or notation patterns.
- Dark luxury/chrome styling.
- Overly sparse product UX that hides room/match state.

## Tilda Motion

Use for:

- Trigger taxonomy: hover, click, scroll, element-on-screen.
- Opacity/transform/rotation/stagger combinations.
- Object-to-object transitions.
- Sequencing language for implementation specs.

Do not use for:

- Tilda page layouts.
- Decorative scroll theater on gameplay-critical paths.
- Long non-interruptible animations.

## Board Game Arena / Lichess

Use for:

- Rooms and lobby clarity.
- Player status and seats.
- Fast return to game.
- Board dominance.
- Mobile usability under real game state.

Do not use for:

- Primary art direction.
- Dense desktop-first controls on mobile.
- Generic dashboard aesthetics.

## Palette Exploration

### Direction A: Warm Daylight Board Game

- Background: warm off-white / pale parchment `#F4E8D4`
- Surface: light oak `#C99258`
- Text: dark ink brown `#2B2118`
- Red: muted clay red `#B94A3C`
- Blue: softened cobalt `#2F6F9F`
- Green: sage board green `#5D7E4A`
- Yellow: warm ochre `#D6A13A`
- Wood: honey oak `#B7773E`
- Accent: brass gold `#C58B35`

Strength: approachable, less heavy than current dark/gold. Best for Telegram readability.

Risk: can become too beige if not balanced with colored pawns and dark text.

### Direction B: Soft Dusk / Muted Atmospheric

- Background: smoky blue-gray `#1F2A30`
- Surface: muted walnut `#6C4A33`
- Text: warm ivory `#F2E8D6`
- Red: ember red `#C45244`
- Blue: dusty blue `#4A7CA5`
- Green: eucalyptus `#6F8C62`
- Yellow: muted saffron `#D9AD4D`
- Wood: dark walnut `#765033`
- Accent: soft amber `#D2A65A`

Strength: keeps drama and depth while avoiding black-luxury casino styling.

Risk: if overused, it can repeat the old dark/gold direction.

### Direction C: Light Editorial / Physical Tabletop

- Background: clean table linen `#EFEAE2`
- Surface: pale maple `#D4B383`
- Text: charcoal `#25282A`
- Red: tomato lacquer `#C94335`
- Blue: ceramic blue `#326D9B`
- Green: muted jade `#4E8A63`
- Yellow: marigold `#D9A52E`
- Wood: maple `#B98B58`
- Accent: amber button `#C9933F`

Strength: modern, clean, physical, and readable. Best candidate for a complete break from the old heavy shell.

Risk: needs careful shadow and depth so it does not become flat.

## Recommended Palette

Direction C for the app baseline, with Direction A warmth in Intro/Result scenes and Direction B reserved only for modal depth or evening atmosphere variants.

## Materials

Recommended primary material: painted wood with a slightly satin finish.

Secondary candidates:

- Matte ceramic for die.
- Soft enamel for pawns if painted wood looks too rustic.
- Wood + painted finish for board fragments.

Avoid:

- Glossy plastic.
- Black chrome.
- Fantasy metal.
- Casino-style gold.

## Typography Direction

- Display: serif only for Zamanushka logotype/title moments.
- Product UI: system sans for labels, status, rooms, lobby, gameplay controls.
- Body: high legibility, no negative tracking on small text.
- Motion labels and room status: compact, specific, not poetic.

## Motion Notes

- Object motion must communicate state: pawn moves because Play was pressed; room expands because it was selected.
- Use short transitions for product state and longer cinematic transition only for Intro.
- Reduced motion keeps the same state changes through fades, highlights, and static before/after states.

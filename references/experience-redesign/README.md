# Zamanushka Experience Redesign References

EPIC-21 captures reference material for a future Zamanushka redesign. This directory is research only: it does not authorize production UI, backend, gameplay, or asset changes.

The new direction treats Zamanushka as an interactive physical board-game world. The reference set is intentionally split by responsibility:

- Interland: experience, spatial storytelling, camera-led onboarding.
- SUGOROCKS: board-game personality, dice/object-driven motion.
- Deep Green: restraint, board-first composition, material quality.
- Tilda motion references: trigger vocabulary and timing patterns.
- Board Game Arena / Lichess: product UX only, especially rooms/lobby/return-to-game.

Screenshot capture status: local Playwright is not installed in this worktree, and the available browser-control surface failed to initialize with a kernel-assets path error. No screenshots were fabricated. Empty `screenshots/` folders are retained for future manual/browser captures.
